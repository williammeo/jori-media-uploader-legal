Privacy Policy

Jori Media Uploader · Last updated 25 November 2026

Jori Media Uploader ("the Tool") is an internal software tool operated by Dalian Jori Co., Ltd. ("we", "us"). It is used only by our own staff, and only to publish video files that we produced ourselves to social media accounts that we ourselves own and operate. It is not offered to the public and it has no end users other than our own employees.

What the Tool handles

Data Why Where it is kept
Video files we produced ourselves To upload them to our own YouTube channel, Facebook Page or TikTok account Our internal file server. A copy is sent to the platform only when we choose to publish.
OAuth access and refresh tokens for our own accounts To call the platform APIs on our own behalf A local file on a computer that we control. Never transmitted to anyone else.
Our own account identifiers (YouTube channel ID, Facebook Page ID, TikTok open_id) and display names To confirm, before every upload, that we are publishing to the correct account of ours and not to somebody else's The same local file
Publish log: file name, video ID, public link, title, timestamp Internal record keeping, so that the same file is not published twice Our internal file server

Use of YouTube API Services

The Tool uses YouTube API Services to upload videos to our own channel. By using the Tool, our staff acknowledge the YouTube Terms of Service.

Our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google's handling of data is described in the Google Privacy Policy.

You can revoke the Tool's access to your Google Account at any time from the Google Account permissions page. Revoking access invalidates the stored tokens immediately.

What the Tool does not do

  • It does not collect data about viewers, subscribers, or any other third party.
  • It does not read comments, messages, followers, or analytics belonging to anyone else.
  • It does not run analytics, advertising identifiers, tracking pixels, or profiling.
  • It does not sell, rent, or share any data with third parties.
  • It does not use the data it handles for advertising, or for any purpose other than the upload described above.
  • This website uses no cookies and loads no third-party scripts.

Retention and deletion

Access tokens expire automatically and are refreshed only while the Tool is in use. Refresh tokens are kept until access is revoked. Video files are deleted from our internal server shortly after a successful publish, and a short-lived backup copy is removed automatically three days after publishing.

To have any stored data deleted, revoke the application from your account settings as described above, or contact us and we will delete the stored credentials and logs.
